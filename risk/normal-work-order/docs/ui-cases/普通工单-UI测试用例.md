## 重要技术约定（执行时务必遵守）

1. **antd Select 下拉**：普通 click 不触发打开，需在 `.ant-select-selector` 上派发 `mousedown`+`mouseup` 事件；选项在 `.ant-select-dropdown:not(.ant-select-dropdown-hidden) .ant-select-item`。
2. **新建工单弹窗「工单名称」字段**与列表筛选框 `#issueName` id 冲突——弹窗字段须用 `.ant-modal` 作用域定位，或先给它打独立 id（如 `#modal_issueName`）再操作。
3. **弹窗内 React 受控输入**：合成 fill 不进 Form state，需用真实键盘输入（CDP `Input.insertText`）；中文必须用 insertText（`dispatchKeyEvent` 不支持中文）。
4. **标签类输入（店铺Handle）**：输入值后须按回车确认成 tag。
5. **弹窗底部按钮（完成/确定）**：用 `.ant-modal-footer .ant-btn-primary` 或去空格按文案精确定位。
6. **行操作**：在 `.ant-table-tbody tr` 内按 a/button 文案定位「查看/删除/复制/编辑」。
7. **审批人下拉**为虚拟滚动用户列表，选 liyanda 需在选项 DOM 中查找（可能需滚动）。
