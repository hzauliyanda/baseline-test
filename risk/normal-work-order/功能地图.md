### 3.3 工单详情（详情页） `/list/detail/{id}`

面包屑：名单申请 / 工单详情。数据：`GET /mapi/cs/issue/normal/{id}`。

#### 信息区块
- **基础信息**：工单名称、工单模板、模板说明。
- **审批信息**：模板字段动态渲染（fieldValues[]，fieldInputType = TEXT/IMG/FILE/ENUM/…），含申请说明、抄送名单(carbonList)。
- **编辑**按钮：进入**内联编辑**，仅可改「抄送人邮箱」，点「确定」保存。
- **审批操作**：备注(approveDesc 输入) + 审核进程时间线(operateLogs：创建工单→各级审批→状态/备注/时间)。
- **驳回 / 通过**按钮：仅当 `canApproval=true` 且当前处理人是自己时显示；点击触发审批。

#### 接口映射（action → api）

| 页面动作 | 触发的接口 | 方法 | 关键参数 |
|---------|-----------|------|---------|
| 打开详情 | `/mapi/cs/issue/normal/{id}` | GET | issueId |
| 点「编辑」改抄送→确定 | `/mapi/cs/issue/normal/edit` | POST | issueId,carbonList |
| 点「通过」 | `/mapi/cs/issue/normal/approve` | POST | issueId,approveDesc,approveStatus=SUCCESS |
| 点「驳回」 | `/mapi/cs/issue/normal/approve` | POST | issueId,approveDesc,approveStatus=REJECT（已实跑验证） |

> 详情字段关键字段：issueStatus、currentHandleUserId/Name、approvalConfig、canApproval、isLastStep、operateLogs、fieldValues。

## 四、页面跳转关系

```text
名单申请 /list（列表页）
  ├── [新建工单] → 新建普通工单弹窗（提交后回列表）
  ├── [查看] → 工单详情 /list/detail/{id}
  │     ├── [编辑] → 内联编辑抄送人（确定/取消）
  │     ├── [通过] / [驳回] → 审批（状态流转）
  │     └── 返回列表
  └── [删除] → 二次确认 → 删除

我已审批 /approved-list（列表页）
  ├── [查看] → 工单详情
  └── [删除]

模版管理 /template（列表页）
  ├── [新增工单模板] → 模板表单弹窗
  └── 行 [复制]/[编辑]/[删除]
```

## 五、核心业务流程

```text
选工单类型 → 选工单模板（拉字段定义） → 填工单名称/主键数据/材料/审批人
  → 完成(POST /save, submitType=ADD) → 生成待审批工单
  → 审批人进详情 → 通过/驳回(POST /approve)
       通过且为末级 → 已完结
       驳回 → 已驳回（可再编辑/废弃）
  → 任意时刻可 删除(DELETE /base/{id})
```

## 六、数据状态流转

```text
待提交(8) ──完成提交──▶ 待审批(1) ──通过──▶ 审批中(2, 多级) ──末级通过──▶ 已完结(4)
                          └──驳回──▶ 已驳回(3) ──（可废弃）──▶ 已废弃(10)
            （任意状态可删除：DELETE /issue/base/{id}）
```

> 单级审批模板：待审批(1) → 通过即 已完结(4)。
